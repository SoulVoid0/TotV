# TotVOS

Voices of the Void 0.9.0n integration for **TotV OS**, an Arch Linux based system that boots straight
into your save:

* the game opens the save named after your OS user, no menu;
* every in-game PC shows the OS's KDE Plasma desktop; using one puts the real desktop over it,
  lined up with your monitor;
* the **VotV PC** app on that desktop runs the game's own PC remotely (all tabs);
* with two or more monitors the inventory opens on the second one.

Requires `Thunderstore-unreal_shimloader`. Outside TotV OS (no bridge running) the mod stays
inactive and the game is unchanged. Source and documentation: https://github.com/SoulVoid0/TotV
(`votv/`).
