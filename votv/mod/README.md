# TotVOS

Voices of the Void 0.9.0n integration for **TotV OS**, an Arch Linux based system that lives
inside the game:

* no main menu: the OS chooses the save (the shared Home save at boot, yours after you log in
  on the in-game PC, any other from the VotV Saves app);
* the **Home** game mode: the real-life clock, never hungry or tired, power that never goes out;
* every in-game PC shows the OS's KDE Plasma desktop, lined up with your monitor;
* the **VotV PC** app runs the game's own PC remotely; with two monitors the inventory opens on
  the second one.

Requires `Thunderstore-unreal_shimloader`. Outside TotV OS (no host) the mod stays inactive and
the game is unchanged. Source and documentation: https://github.com/SoulVoid0/TotV (`votv/`).
