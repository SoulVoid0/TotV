# TotV

* [`os/`](os/README.md): TotV, an Arch Linux based operating system with
  LSIW (C: drive = `/`), and its USB installer.
* [`tools/write-usb.sh`](tools/write-usb.sh): write the installer ISO to a
  USB stick.

Download the installer ISO from the latest **Build TotV OS** workflow run or
from the releases, write it to a USB stick, boot it, and follow the
installer. See [os/README.md](os/README.md).
